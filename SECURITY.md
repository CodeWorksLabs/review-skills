# Security and disclosure

Review methods are public by default. Reports must not expose credentials, protected infrastructure, customer data, private source, or actionable details of an unresolved vulnerability.

When a review discovers an exploitable security issue:

1. preserve the exact evidence privately;
2. notify the responsible maintainer through an appropriate private channel;
3. coordinate correction and disclosure;
4. publish a sanitized report only when doing so no longer creates unreasonable risk.

Security concerns involving this repository may be reported through GitHub private vulnerability reporting when available, or through a private CodeWorksLabs contact channel. Do not open a public issue containing an active exploit or secret.
